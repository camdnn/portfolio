# Portfolio

Camden Mann's personal portfolio site, read by hiring managers and technical interviewers deciding whether to interview Camden.

## Language

**Selected Work**:
The curated set of 3–5 projects featured on the home page, ordered by strength of evidence.
_Avoid_: Projects, portfolio items, showcase

**Flagship Project**:
A Selected Work entry backed by an inspectable repository Camden substantially authored, which earns a Case Study.
_Avoid_: Featured project, highlight

**Case Study**:
A short page for one Flagship Project answering what it does, why it matters, what Camden personally built, and how to inspect the code.
_Avoid_: Project page, deep dive, write-up

**View Source**:
The link from a project to the most relevant repository, branch, or directory Camden authored — never Camden's GitHub profile.
_Avoid_: Code link, GitHub link

**Evidence**:
A verifiable artifact behind a claim: a repository, commit, test, README, CI run, deployment, demo, or sourced metric.
_Avoid_: Proof, highlights

**Claim**:
Any statement on the site about what a project does, who built it, or what it achieved; every Claim must have Evidence or come from Camden.
_Avoid_: Blurb, description
